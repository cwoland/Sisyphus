# Проверка исправлений

## Локальные проверки

```sh
npm ci
npm run lint
npm test
npm run build
```

В соседнем репозитории `Sisyphus-server`: `npm ci` и `npm test`.
Серверные тесты запускают отдельный PostgreSQL-совместимый движок PGlite в памяти.
Они не используют `.env`, Render или Supabase.

## Проверка интерфейса

```sh
npx playwright install chromium webkit
npm run dev -- --host 127.0.0.1
# В другом терминале:
npm run test:browser
```

Браузерный сценарий подменяет ответы API тестовыми данными. Проверяет календарь
на ширине 320, 375, 390 и 430 px, вложенные окна и блокировку прокрутки,
порядок суперсета, отсутствие отдыха между дропами и сохранение сообщения при ошибке.
Скриншоты сохраняются в `/tmp/sisyphus-calendar-<engine>.png`
и `/tmp/sisyphus-workout-<engine>.png`.

## Порядок выпуска

1. Выпустить бэкенд с миграцией `1793900000000_workout-reliability.js`.
   Существующий `npm start` запускает `migrate:deploy` перед сервером.
2. Выпустить фронтенд. В production запросы идут через `/api` и существующий
   Vercel rewrite на Render; refresh cookie остаётся same-origin.
3. Применить обновление PWA. Проверить календарь, ввод даты и возврат из клавиатуры
   на физическом iPhone 12, включая повторное открытие установленного приложения.

Миграция оставляет активной последнюю начатую тренировку пользователя,
а прежние активные возвращает в запланированные с сохранением подходов.
Она также исправляет старую группировку вручную добавленных упражнений,
расширяет поле расчётного рекорда и добавляет дату последнего напоминания.

Старые офлайн-действия без идентификатора владельца не отправляются автоматически:
надёжно определить их аккаунт невозможно. Новые действия разделены по владельцам.
Неудачная доставка push снимает отметку отправки для следующей попытки.

Эмуляция WebKit не заменяет проверку установленной PWA и клавиатуры на iPhone.
Предварительная настройка дропсета в конструкторе и генерация программ ИИ относятся
к новым возможностям и в этот пакет исправлений не входят.

## Результаты локальной проверки

- `npm run lint`, `npm test`, `npm run build` на фронтенде: успешно.
- `npm test` на бэкенде: успешно, включая SQL миграции и сценарии исправления рекордов.
- Chromium с параметрами iPhone 12: проверки интерфейса прошли.
- WebKit: в этом окружении зависает создание страницы; успешный прогон не подтверждён.
- Физический iPhone 12 и production: не проверялись, деплой не выполнялся.
