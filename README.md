### Sisyphus ###

A fitness tracking app for bodybuilders and keen sportsmen. Includes program building, active workout screen, nutrition tracking, friends & feed screen, chat and AI assistance. 

-- Stack --

### FRONTEND ###
React 18, JavaScript (ES6+), TailwindCSS, Zustand, Tanstack Query, Axios, Lucide React, Framer Motion

PWA available:
